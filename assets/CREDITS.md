# Asset Credits

All art and audio shipped in this folder is **generated procedurally by this
project itself** — no third-party asset packs are used.

| Path | Content | License |
| --- | --- | --- |
| `sprites/*.png` | Player paddle, collectibles, bomb, power-up plates | CC0 1.0 Universal |
| `sounds/*.wav` | catch / bomb / gameover effects (44.1 kHz mono PCM) | CC0 1.0 Universal |

Every file can be regenerated from source at any time:

```bash
python tools/generate_assets.py
```
